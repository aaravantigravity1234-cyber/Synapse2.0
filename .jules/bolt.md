## 2026-05-10 - Throttle High-Frequency DOM Events
**Learning:** High-frequency frontend event handlers (like 'scroll' or 'resize') that read layout-triggering properties (e.g., `scrollHeight`, `scrollY`, `innerHeight`) must read these values *inside* a `window.requestAnimationFrame()` callback with a ticking flag to prevent synchronous layout thrashing. Conversely, coordinate tracking (like `mousemove` `clientX`/`clientY`) should capture values *outside* the callback, as tracking the event object directly within the closure can drop final updates during rapid bursts.
**Action:** Always use `requestAnimationFrame` with a ticking flag for high-frequency events. Ensure layout property reads happen inside the `rAF` frame and event object data extraction happens immediately in the event listener before scheduling the `rAF`.

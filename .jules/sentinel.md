## 2024-05-24 - Cross-Site Scripting (XSS) via Inline Handlers and Missing Attribute Escaping
**Vulnerability:** The application was vulnerable to Cross-Site Scripting (XSS) due to dynamic unescaped variables being injected directly into HTML strings within `frontend/js/chat.js` (e.g. `onclick` attribute and `alt` attribute of images). `escapeHtml` was insufficient as it didn't encode quotes.
**Learning:** Browsers decode HTML entities within inline event handlers (`onclick="..."`) BEFORE JavaScript execution. Therefore, escaping content via `escapeHtml` (even if it escapes quotes) is completely ineffective for inline event handlers, as the quotes get decoded and the payload breaks out of the attribute to execute JavaScript. This is a critical edge case to remember when dealing with vanilla JS DOM manipulation.
**Prevention:** Never inject dynamic data directly into inline JavaScript event handlers. Always attach dynamic variables using data attributes (`dataset`) and use standard `addEventListener` to handle user interactions securely. Always use a dedicated `escapeAttribute` function (that escapes double/single quotes) when injecting values into standard HTML attributes.

## 2024-05-18 - [XSS via Inline JS Event Handlers and Attribute Breakout]
**Vulnerability:** XSS vulnerabilities found in frontend/js/chat.js where untrusted string interpolation was used within inline JavaScript event handlers (e.g., `onclick="switchToModel('${originalModel}')"`) and within HTML attribute tags, such as `alt="${escapeHtml(file.filename)}"`.
**Learning:** Browsers decode HTML entities before executing JavaScript inside inline event handlers, meaning that natively escaping strings using `escapeHtml` does not protect against XSS if the string is used inside `onclick` or other inline handlers. Furthermore, a simple `escapeHtml` implementation that does not escape single and double quotes leaves attributes vulnerable to breakout attacks if an attacker injects quotes.
**Prevention:** Avoid inline JavaScript event handlers (`onclick="..."`) for elements needing dynamic text injection. Create elements programmatically via DOM APIs (e.g. `document.createElement`) and assign event listeners via object properties (`.onclick = () => { ... }`) or `addEventListener`. When writing variables into attributes within string interpolation, always use an `escapeAttribute` function that converts single and double quotes to their corresponding HTML entities.
